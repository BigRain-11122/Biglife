# BigLife 基因轮（extend-gene-pool）

## 0 铁律（先读）

- 纯尾部定点追加：只允许在既有数组末尾追加（diff 仅尾行加逗号+新行）；既有基因零字节改动。
- 全库零重复：库内+新内零重复（含 6 字字面重叠扫描）；跨面（pools/greetings/negative）双向包含扫描防撞句。
- 万卡零触碰：genes/=生产资料；census 万卡=活户籍，禁重生成联动。
- 触发词族纪律：新基因字符级避开机审门 token 族——雨/淋/台风/风量级词/天体（月星）/晴系/雾/时段晨夜词/占位词/信号灯/场次/放学（R40 纪律）。
- 先登记后使用：新基因先入 genes/ 再被生成器引用；禁在卡面直接手写新基因。

## 1 步骤（命令式）

1. 拟候选：口头禅 +6（六轴各 1 平衡：逍遥/烟火/秩序/求新/怀旧/侠气）+钩子物件 +4（市井旧物·具象可挂场景）；转折点按同法。
2. 预检三查（禁省）：
   - 查一 唯一性：python Counter 全库校验+新候选 6 字重叠扫描；近重候选换句再验（R149 近重防线）。
   - 查二 触发词族零命中：字符级扫描新候选（族表见 §0）。
   - 查三 跨面零撞句：新候选对 cognition/pools.json+greetings.json+负面面双向包含扫描（R102 跨面撞句教训）。
3. 纯尾追加：编辑 genes/ 对应库文件（尾行加逗号+新行），`json.load` 双件过。
4. 终验：Counter 基线计数（口头禅 N→N+6·钩子 M→M+4）+diff 纯新增断言（禁出现删改行）+`json.load` 复过。

## 2 判例指针

R40 触发词族纪律立线 / R102 跨面撞句实弹（新句与问候库撞·当轮拦下双修）/ R149 近重候选三换句实录 / R249 预检抓撞实录——详 tasks/TASKS.md 对应轮迭代批实录。
