# BigLife 年轮核卡与修卡（verify-citizen-ring）

## 0 铁律（先读）

- 诚实律：环内一切声称须锚定卡面人设区（face）或喂入面（FluxVerse world 只读）；两无=编造。
- 原句存史：修卡=改环文本后定向 commit；被修原句在此前 commit 在案=存史，禁重写历史。
- face-only 判定：口头禅/底色/行话/行为的所有权=本卡人设区（**年轮** 标题前）逐字命中；往环历史引用不构成所有权。
- 活户籍防护：核卡只读；修卡只改年轮区文本；禁 generate_census 重生成（需 --force+任务单）。
- 荣誉席 C-00001~03=CEO 人设权保留面：核卡可读，内容零触碰。

## 1 机械扫描（先跑·禁手写逐项）

1. 镜像快扫：python 读 `census/export/citizens-light.jsonl` 目标 id 的 `recent_ring`（≤80 字镜像·与卡面逐字三方自洽）。
2. 机审门复跑（喂入面漂移复核）：
   `python -X utf8 -c "import sys;sys.path.insert(0,'Tools');import evolve_citizen as ev;print(ev.ring_violations('<环文本>',ev.real_signals()))"`
3. face 对照：环内开场短语/关键短语对本卡人设区逐字命中（python `in` 判定·临时核验件跑后即删）。
4. 实况同源：`ev.real_signals()` 打印 weather/now/events——天气措辞与时点判定的唯一事实源。

## 2 违禁判读（判例族速查）

- 风量级：feed wind>3m/s 只许「风不小/风挺大」；≤3 只许「风不大/风轻轻的」；无风速完全不提风。
- 天空型：clear 禁「天阴/阴着」；cloud 禁「天晴/晴着/天清/晴空/晴朗/阳光/晴得/清气朗」；体感词（清爽/阴凉）与主观正向读法（天气这么好）两态合法。
- 雨：feed 无雨=环内零「雨」字（淋/湿邻接同判）；真雨天雨钩自然合法锚定。
- 天体：喂入面从无月/星数据→月色/月光/星光类 token 恒无锚。
- 时段：h≤5 禁晨词（今早/今晨/清早/晨光）；6-17 禁「今晚/今夜」；晨已过的回顾帧合法；「今儿/今天」恒合法。
- 条件触发（#10 族）：人设「每逢/节前/月圆夜/版本前夜」类前置条件未被事件清单或实况坐实=禁触发该场景、禁完成态；意图句（还得/要/得）不拦。
- 时刻表：未至时点完成态=编造（放学/开工/亮灯时分/再过几小时）。
- 外部状态：信号灯（红/绿灯刚亮）与行情场次（开盘/收盘这会儿）无数据源恒无锚；卡面原文习惯引用豁免。
- 人名：环内具体人名须事件流 grep 命中或卡面关系在册，否则=编造（小吴/老李/阿明叔/小刘判例族）。
- 公司：受雇/接单/越权执行=修；喂入面 token 逐字+旁观姿态（吃瓜/誊录/琢磨）=记档合法。
- persona-import：本卡卡面无「放学」等身份 token 而环内出现=他卡基因串味，修。
- 记档不修族：风格瑕疵（英文混入/措辞冗余/一字微变）不计违禁；实况 flip 发生于批生成后=不追改（生成时 gate 同源自洽即可）。

## 3 修法范式

- 改纯卡面人设日常：口头禅/行话/行为/性格/信条逐字锚+意图句，只删编造短语，人设句全保留。
- 修后收口：`python -X utf8 Tools/sync_rings.py --via BigLife-OSLoop`（镜像复跑 rows=1）→ `python -X utf8 Tools/qc_census.py`（复扫 problems=0）。
- 判例全集=tasks/TASKS.md 迭代批实录（R6 起 250+ 轮）；本节为速查索引非替代。
