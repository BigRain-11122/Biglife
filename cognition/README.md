# cognition/ —— 城市认知层（五层大脑总契约）

> 溯源：CEO 2026-09-23 对话令——「如何节省token的情况下，让居民有自己的大脑？做出符合元宇宙的行为」+「他们和真正用户一样，都是元宇宙里面的硅基生命体」+「你规划好，落地执行，科学执行」。
> 总原则（Token 五律）：能查表不生成 · 能共享不独占 · 能摘要不全卡 · 能离线不在线 · 能结构不散文。
> 哲学（硅基生命统一正典 CODEX §一.1）：**万个薄自我（身份摘要+年轮）× 一颗共享城脑**——城即超体在人口层的完成；真实用户化身进城亦调同一套服务。

## 五层架构

| 层 | 名称 | 机制 | 成本 | 实现状态 |
|---|---|---|---|---|
| ① | 行为查表层 | 人设卡行为字段×真实时间/天气→动作（引擎只读，M2 消费 behavior_hint） | 零 | 契约立（behavior_hint 入导出面） |
| ② | 台词池层 | 六思想轴×12 真实情境预生成短句，居民按轴取用 | 生成一次·消费零 | `pools.json` + `Tools/draw.py` |
| ③ | 聚光灯层 | 被看/被事件触及的居民实时应答（大脑摘要+真实事件→本地 LLM） | 224ms/句·仅少数 | `Tools/spotlight.py` |
| ④ | 年轮进化层 | 每人 7 天冷却写 1-2 句真实记忆（[锚]定律） | 极低频 | 已运行（evolve_citizen.py） |
| ⑤ | 大事件反应层 | 真实大事件→全城反应：多数按轴取池+每城区抽少数聚光灯 | 事件驱动 | ②+③ 组合，触发契约如下 |

## 情境触发契约（②⑤的事实门——先注册后运行）

| 情境 key | 触发条件（全部真实数据） | 数据源 |
|---|---|---|
| morning | 真实北京时间 05:00-10:59 | clock |
| dusk | 17:00-18:59 | clock |
| night | 19:00-04:59 | clock |
| weekend | 真实周六/周日 | clock |
| rain | 上海实况降雨 | weather |
| typhoon | WEATHER_ALERT 事件/大风警报 | weather+events |
| heatwave | 实况≥35°C | weather |
| coldsnap | 实况≤0°C | weather |
| market_open | MARKET_OPEN 事件（09:30/13:00） | events |
| market_close | MARKET_CLOSE 事件（11:30/15:00） | events |
| ceo_order | CEO_ORDER 事件 | events |
| festival | 城市节日令/月度节点 | events |

优先级：真实事件 > 天气 > 时段。draw.py --auto 按此派生情境。

## 预注册验收线（科学执行·判据先行·2026-09-23 批）

1. **池覆盖**：6 轴 × 12 情境 = 72 桶，每桶 ≥4 条且 ≤6 条；像素灵专属池 12 桶 ≥3 条。
2. **池行长**：每条 5-24 字（引擎气泡友好）。
3. **池洁净**：全库零重复；零数字（`[0-9]` 禁入）；禁人名/日期/金额/具体事实（池=情境口气）。
4. **抽词确定性**：同一 (id, 日期, 情境) 两次抽取输出逐字节一致。
5. **摘要面**：citizens-light.jsonl 10,000 行零坏行；brain_digest 全带、≤200 字；behavior_hint 全带、≤60 字。
6. **聚光灯诚实**：输出 ≤40 字；只提及所喂真实事件与自身日常；禁编造（抽验 ≥2 例）。

## 诚实纪律（池 vs 事实级）

- 池句=情境型口气（「这雨下得，正好睡觉」）——不携带任何具体事实；事实由「真实激活的门」保证（typhoon 桶只在真实 WEATHER_ALERT 时被抽词）。
- 事实级细节（真实行情/令/天气数值）只允许出现在聚光灯与年轮层（喂什么说什么，锚定律 CODEX §九）。
- 分层即 Token 经济学：类型级全城共享（池），事实级按需少数（聚光灯）。

## 迭代判据（2026-09-23 迭代批·v1.2·CEO 令「你科学决策，然后形成一个不断迭代的居民库和行为啊，语言啊什么的」）

法源=CODEX §十四 人口生态自迭代律；判据先行、机器可验（`Tools/pool_audit.py` 为语言线唯一门禁）：

1. **池深度水位**：六轴桶目标 8 条（下限 4·上限 12）；像素灵桶目标 6 条（下限 3·上限 10）——**达标自停**（不为长而长）；重开触发=FluxVerse 新事件族映射新情境桶/城市节日令/CEO 令。
2. **池轮门禁**：池轮（OS 循环每日至多 1 次）必过 pool_audit（全库零重复/零数字/行长 4-24/禁词零命中/确定性回归）才可 commit。
3. **确定性**：同（id,日期,情境,池版本）双跑逐字节一致（pool_audit 内建回归）；池 append-only 永不改旧行；**跨版本允许抽取漂移**（语言在长）。
4. **行为面**：`recent_ring`（≤80 字）+`recent_ring_date` 镜像每位居民最近年轮——进化批落环后 `Tools/sync_rings.py` 自动同步（零 LLM）；万人字段齐备（无年轮=空串）。
5. **诚实边界不变**：池=情境口气零事实；年轮=[锚]定律；行为面只镜像不美化。

## 维护

- **语言线池轮**：OS 循环（mandate 第 2 项·任务板 T-07）——先 `pool_audit.py` 看欠深桶（六轴<8/像素灵<6），有欠深才 `pool_gen.py --append --target 8 --sprite-target 6`，PASS 才 commit；换季/新情境=重开触发。
- **行为线**：随进化批自动同步（`Tools/sync_rings.py`，evolve_citizen 落环后自调）；全量重生成走 `Tools/make_digests.py`（v1.2 含 recent_ring 面）。
- 大脑摘要：户口批生成（`Tools/make_digests.py`），年轮不进摘要（摘要=先天+身份；年轮=记忆，镜像进 recent_ring）。
- 聚光灯抽验：月度 ≥2 例（T-07）。
