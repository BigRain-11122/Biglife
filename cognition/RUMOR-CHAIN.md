> 引擎=`Tools/rumor_chain.py`（下轮落件·零 LLM 零 API·纯确定性）；本契约为引擎验收判据，全过才关分单。

## 一 接口（按需调用面·非 R3 再生面·不入 census/export 正典面）

```
python -X utf8 Tools/rumor_chain.py --event-id ID --event-text "文本" --seed C-xxxxx \
  [--hops 3] [--cool-min 60] [--at "YYYY-MM-DD HH:MM"] [--out 路径] [--qc]
```

输出：JSON 一对象=`{event_id, seed, hops, cool_min, at, engine_v, hops:[{hop, from, to, ts, text, op}]}`；`--out` 落文件，缺省 stdout。

## 二 验收判据（门禁）

1. **确定性**：同 (event, seed, 参数) 双跑输出逐字节一致——选跳/延迟/失真全 md5 派生（`python hash()` 进程随机化禁用=behavior.py 同律）。
2. **跳数参数化**：`--hops` 有效域 1..6，默认 3；产出跳数=参数值。
3. **冷却参数化**：`--cool-min` 默认 60；相邻跳 ts 间隔 ≥ cool-min（确定性延迟=cool-min + md5%cool-min，上界 2×cool-min——事件不瞬移）；`cool-min=0` 合法（不冷却档·FP 护栏）。
4. **失真有界零编造**：每跳至多 1 次闭集变换 `{截尾(末分句)、数字模糊(阿拉伯数字→「几」)、垫话前缀(「听说」「好像」二选一)、无操作}`；输出字符集 ⊆ 原事件文本 ∪ 垫话闭集——零新增事实。垫话系流言面角色真实转述语义，与年轮面「天气消息源归属禁令」（缺口#8 族）不冲突：本面禁含天气/天体/时段词族（机审门触发词族规避=R40 纪律）。
5. **选人词域**：同城区优先（seed 城区池，池尽则全城池）；链内居民去重（一人一链一次=链内冷却）+时间冷却（判据 3）双面。
6. **--qc 自检**：判据 1-5 断言全过（双跑逐字节一致+跳数/冷却边界+失真闭集+链内零重复+cool-min=0 护栏）才 PASS。
