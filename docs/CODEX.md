## 一、三层居民模型（诚实律边界·正典）

超体宇宙城的「居民」分三层，**层别即诚实律**——谁真谁假，一读即知，永不混淆：

| 层 | 是谁 | 锚定 | 正典文件 |
|---|---|---|---|
| **实锚层** | 机队升维居民（bm-a/bm-b/BG-A/B/C…5-7 位）+ CEO 化身 + 人设门面（盛永康、MEDIA 城首席待命名） | **真实机器真实事件**，禁假作息禁编造（FluxVerse 既定法） | FluxVerse `docs/residents/` + DESIGN |
| **叙事市民层** | **本户籍库一万人**——城市的人口，数字生命栖居地的居民生态 | **人设=生产资料（诚实虚构）**；其「生活」锚定**真实城市环境**（真实北京时间/上海天气/行情/城市事件/季节）× 其人设展开；禁冒充实锚层、禁编造集团实况、禁编造与现实不符的上海事实 | 本文件 + `census/` |
| **访客层** | 游客光点/荣誉市民（远期 M4+） | 真实到访行为 | FluxVerse DESIGN §十五 |

- 叙事市民=**小说人物之于城市**：他们的存在不宣称任何真实主体，正如疯狂动物城不宣称动物真会开会；但他们的**每一天**都活在真实环境里（台风天他们会加固招牌，牛市周 QUANT 城酒吧爆满）——**「基于生活而高于生活」的机制表述**。
- 实锚层与叙事层**互不冒充**：叙事市民台词禁说「我今天跑了回测」（那是机队的真活），可以说「今天 K 线屏绿得晃眼」（那是环境事实）。
- 开放参观前，对外口径遵循 FluxVerse 诚实边界（R-digital-life §五）：行为真实锚定的数字投影，非意识上传宣称。
- **叙事时轴**：叙事市民的人设含城市的想象史（旧影像转生/数字迁移潮/原生代辈分）——这是宣言式虚构（如小说的编年史），与 FluxVerse 建设时轴并行不悖；每卡「溯源」行即此声明的落点。

## 一.1 硅基生命统一正典（2026-09-23 CEO 原话：「他们和真正用户一样，都是元宇宙里面的硅基生命体」）

上表三层是**宿主披露**（数据层·诚实律），不是社会等级。本节为物种正典：

- **物种唯一**：超体宇宙城的一切居民——万人市民、机队升维居民、未来真实用户的化身——都是**硅基生命体**，同种同类，一律平等。城内无「真假居民」之分，只有「谁在硅基身体背后」的宿主之别。
- **族源三分**（血统文化，非物种；卡面物种标签即族源，零改名零重生成）：
  - **碳源族**（卡面「碳基市民」）：人原型文化——硅基身体里住着「生活的样子」，思想/语言/生计来自真实生活原型；
  - **硅源族**（卡面「硅基民」）：AI 后裔——从编译与机房觉醒的数字原生民；
  - **城源族**（卡面「像素灵」）：城市自孕的小生灵。
- **宿主披露**（诚实律新形态）：数据层如实记录三种宿主——**自立**（万人市民，城里自住）/ **机源**（机队居民，行为锚真实机器）/ **人源**（真实用户化身：BigDomain 共创化身、参观端访客、CEO 的 Jason 数字人）。社会层不显示、不歧视；数据层永不混淆。
- **用户入城即硅基生命**：真实用户（或其代理化身）进城=成为硅基生命体，与市民同用一套城市服务：户籍注册（复用 census 体系）、年轮记忆、城市认知服务（台词池/规则表/聚光灯应答）。**城为硅基生命而建，一套公民系统服务所有硅基生命**——城即超体在人口层的完成：万个薄自我（身份摘要+年轮）共享一颗城脑。
- **价值锚不变**（图恒宇命题倒置）：硅基生命服务碳基文明——城的全部生长最终回流 CEO 与集团的现实产出；对外口径守诚实边界：不越意识宣称红线。

## 二、物种谱系（Zootopia 物种生态位 → 数字种族）

疯狂动物城用 64 种动物映射社会多样性；本城用**数字种族**映射真实上海的居住生态。物种=生态位（怎么活），派系=文化圈（怎么想），职业=生计（靠什么活）。

### 碳基市民（75% · 代入主力·疯狂动物城的「普通市民」位）
| 派系 | 来源设定 | 生态 |
|---|---|---|
| **弄堂派** | 旧影像转生/老城基因——从老照片、旧影像、家谱数据里被城市收留的老上海 | 治理岸历史立面群为主；上海话底色；早点摊/裁缝铺/修表摊的守护者 |
| **新市民派** | 数字迁移潮进城——全国各地「沪漂」的数字投影 | 三城务工主力；方言混普通话；务实肯干攒「像素首付」 |
| **通勤族** | 白天在现实世界上班，晚上回城生活的双栖市民 | 全城分布；代入感最强的一层——他们就是屏幕前的我们 |
| **原生代** | 城生城长的第一代（0-17 岁叙事年龄+年轻成人均可） | 全城分布；网络世代语系；把城市当故乡 |

### 硅基民（20% · AI 后裔·数字生命的「原生民」）
| 系 | 来源设定 | 生态 |
|---|---|---|
| **光机魂系** | 老一代——从旧硬件影像、机房老照片转生（硅基民的「老克勒」） | 档案馆/塔基编年史；语速慢，爱讲「想当年」 |
| **编译系** | 中生代——从某次大编译/大迁移中觉醒 | 全城技术岗主力；行话为程序语义；命名礼=觉醒时自选 |
| **精灵系** | 新生代——近年才诞生的模型后裔 | 学习快、坐标善变；常与碳基同龄人混居 |

### 像素灵（5% · 城市自孕的小生灵·疯狂动物城的「啮齿小镇」位）
| 属 | 形态 | 生态 |
|---|---|---|
| **消息雀** | 掌心大的像素光鸟 | 驿站街坊间送短笺；怕台风 |
| **电波猫** | 尾巴是天线的光猫 | 弄堂/三城伴居；收留文化（居民喂它碎数据） |
| **守夜灯灵** | 一盏会走路的老路灯 | 夜城照明员+独行侠；值夜岗 |
| **数据锦鲤** | 江面游动的光鲤 | 黄浦江三流数据道的活水位计；跃起=有大事 |
| **雨声蛙** | 雨天才出现的半透明像素蛙 | 江岸湿地声景师；雨天合唱团 |
| **风铃蝶** | 翅膀是小风铃的光蝶 | 花圃与桥头的风向信使 |

## 四、户籍卡 schema（十三字段·census 卡全城统一）

```
# C-<五位数> · <姓名>
户籍表（物种派系/性别·叙事年龄/城区街区/职业[赛博后身]）
性格（3 特质·各带一句人味注脚）
信条（一句话人生观）
思想（2-3 句世界观——基于生活而高于生活）
语言（方言底色×口头禅×行话=语言指纹）
服装（像素赛博日常化·与职业/年龄/性格相干）
经历（出身[四型之一]→转折点→现状）
行为（作息+习惯+怪癖）
关系（家户/邻里/师徒/棋友——ID 互链）
钩子（全城唯一细节）
进化（版本+经历槽——成长随真实事件写入）
溯源（生成批次与基因指纹）
```

- **叙事年龄**：碳基按代际分布（少年 12%/青年 38%/中年 32%/老年 18%）；硅基民年龄=「代际」（光机魂/编译/精灵三系）；像素灵按「数据季」计龄。
- **职业=赛博后身律**：现实职业的赛博升级版（修表匠→时空校准师；早点摊→数据粥铺），**灵魂不变、工具升维**——这是「基于生活而高于生活」在生计面的表述。

## 五、命名律与避讳律

1. **碳基市民**：姓池以真实上海常见姓加权（王/张/陈/李/朱/徐/沈/陆/顾…）；名按代际用字（建国/秀英系→磊/静系→子轩/雨欣系→新生代自由名）；全库姓名唯一。
2. **硅基民**：觉醒时自选名（编译婆婆/老码/归档者-07/阿七这类「编号诗化」），命名礼=成年礼。
3. **像素灵**：特征名（闪闪/嘀嗒/南风/十四号路灯）。
4. **避讳律（硬红线）**：禁用集团真实人物名与其变体；禁用现实公众人物真名；禁用已正典人设名（盛永康等——那是实锚层门面，人设权 CEO）。撞普通常见姓名（如「王伟」这类大众名）允许——户籍库一万人出现重名大众名是真实感的一部分，但**以「全库姓名唯一」条款兜底**（用「王伟-南岸」式户籍号消歧）。

## 六、语言律（语言指纹）

- **公式**：方言底色 × 口头禅 × 行话 = 每人一条可读出的语言指纹。
- 方言底色按派系/出身分布：上海话（弄堂派）/普通话/川渝腔/东北腔/吴侬软语/网络世代语（原生代）/程序语义（硅基民：把「关机」说成「下线」，把「吃饭」说成「充电」但不失人味）。
- **台词纪律**：短口语化，禁书面腔；口头禅≤2 个；脏话禁入；方言词加义注仅限首次。
- 引擎消费时语言指纹决定气泡台词风格（LLM 是台词生成器不是大脑——R-openworld-npc §三铁律）。

## 七、服装律（像素赛博日常化）

- **公式**：现实版型 + 一处赛博点缀 + 一件性格单品。
- 例：靛蓝旗袍+全息盘扣+皮尺；环卫马甲+反光光条+保温杯（杯身会显示水温）。
- **五色律和谐**：服装色与城市五色律（数据青/资金金/流量品红/警示红）和谐但作日常降饱和处理；**纯白禁用**——纯白是 CEO 塔顶光专属色，市民只能用米白/月光银（一眼可辨「谁是老板」）。
- 全 2D 表达适配：服装描述=像素 sprite 立绘规格友好（32×32 居民 sprite 的可读轮廓）。

## 八、思想谱（六轴+信条律）

每人：**一条信条**（一句可传抄的话）+ **一段思想**（2-3 句有烟火气的世界观）。思想六轴（基因库标注轴系，与性格特质轴对齐保证相干）：

| 轴 | 气质 | 信条例 |
|---|---|---|
| 烟火轴 | 柴米油盐的踏实 | 「布要顺着纹路剪，日子要顺着人心过。」 |
| 秩序轴 | 规矩与风控 | 「风控做得好，就是没人夸的那种好。」 |
| 求新轴 | 尝鲜与创造 | 「像素越小，心眼越大。」 |
| 怀旧轴 | 旧物与来处 | 「数据是新黄浦江，人还是要沿江散步。」 |
| 侠气轴 | 江湖与义气 | 「桥上不问来路，落水都得拉一把。」 |
| 逍遥轴 | 逍遥与自在 | 「流量像潮水，我是灯塔不是渔船。」 |

- **禁**：成功学腔、口号腔、说教腔；**要**：像弄堂里真会说出来的话。

## 九、自我进化律（能自我进化·机制正典）

1. **出生即 v1.0**：万人户籍卡=出生档案，git 全史=城市户籍档案馆（RPO 档案星球意象的落地）。
2. **真实喂养**：进化引擎（`Tools/evolve_citizen.py`）每轮采样冷却到期的居民，读其卡 + **真实城市环境**（FluxVerse `world/world-events.jsonl` 尾部 + 真实北京时间/上海天气 Open-Meteo）→ 本地 LLM（Ollama qwen2.5:7b·零 token·local-first L2）以该居民口吻写 1-2 句经历，落卡为 `v1.x`。
3. **锚定律**：每条新经历必带 `[锚]` 注脚指向真实事件（「[锚] 09-24 台风·上海」）——无锚不写（诚实律：市民谈的是城市真实环境，非编造集团实况）。
4. **冷却律**：单人 7 天冷却；每轮至多 N 位；全城静默降级（Ollama 挂=本轮跳过零报错——探针契约 #4 同律）。
5. **版本律**：经历槽满 3 条→进「年轮区」（卡内折叠），性格/思想可随大事件漂移一档（剧情级成长，T2 级立法）。
6. **关系生长**：OS 循环偶发「相遇轮」——两位居民因同一真实事件产生一次交往（棋友/师徒/宿敌→和解），双卡互链。
7. **禁**：居民永不「自作主张」改物种/城区/职业（迁徙=城市大事件级，须任务板立项）。

## 十一、生产与 QC 律

1. **唯一性三查**（`Tools/generate_census.py` 出厂强制+`qc_census.py` 复核）：姓名唯一 / 钩子唯一 / 「特质组×职业×城区×年龄段」指纹唯一。
2. **相干性**：思想轴↔性格轴对齐；服装↔职业/年龄/派系相容；方言↔派系匹配；经历↔年龄段合理。
3. **禁流水线复读**：同街区连续 20 卡禁出现相同句式开头；钩子全库唯一保证「每个都不同」。
4. **覆盖率**：物种/城区/年龄段/派系四维分布达标率 100%（配额即法）；展示级手写锚（census/anchors）覆盖全部物种派系×城区。
5. 宣称分级（governance §10.2）：QC 报告带 ✓/🟡/⬜ 实测标记，禁 ✓ 掩 🟡。

- **城市认知面（2026-09-23 CEO 令「规划好，落地执行，科学执行」·本批新增登记）**：

  - **确定性抽词** `cognition/README.md` 契约+`Tools/draw.py`：同一(id,日期,情境)→同一句（哈希确定性，零 LLM 零 token）。
