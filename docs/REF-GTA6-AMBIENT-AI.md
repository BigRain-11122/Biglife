# 借鉴：GTA/RDR 的「环境 AI」四件套 → 我们的文本城市怎么落

> 说明：Rockstar 没有公开 GTA6 的 NPC 技术论文。以下区分两类：
> **【公开】**＝官方访谈/游戏内可直接观察的机制；**【推断】**＝我从公开现象反推的工程做法。
> 只借**机制**，不复刻美术与内容。

## 一、四个可迁移机制

### 1. 日程表（schedule）【公开：RDR2 访谈里明确讲过 NPC 有作息】
NPC 不是随机行动，而是"这个点该在哪、该做什么"由日程决定；玩家能感到"世界在自己运转"。
**落到我们这里**：年轮里"这个点儿我在摊上/在码头/在屋里补觉"应由 `(职业, 年龄, 小时)` 决定，
而不是每轮随机。现在我们有"行为"字段，但没有**时钟驱动**——所以读起来是"任意时刻的一天"，
不是"此刻的一天"。这是我们和它的第一差距。

### 2. 目击与记忆（witness → memory）【公开：犯罪被目击会被告发】
NPC 看见一件事 → 记住 → 影响之后的行为（告发、躲避、议论）。
**落到我们这里**：事件流里的每条事件都有 `zone`；居民有 `城区`。二者匹配＝"我在场，我看见了"。
把它写进 memory stream 并给高 importance——**同一条城市事件，只有在场的人记得**。
这一条我们已有零件（事件带 zone、记忆带 importance），缺的是"在场判定"这一步。

### 3. 态度值（attitude / honor）【公开：RDR2 的荣誉与 NPC 反应】
NPC 对你的态度是**连续量**，不是"朋友/陌生人"两档；它随行为变，且会外显（招呼/冷脸）。
**落到我们这里**：关系现在只有标签（棋友/常客）+ 双向边，**没有强度**。
加 0–100 的强度，相遇 +N、被插话/砍价 −N，下一轮措辞受影响（热络/冷淡）。

### 4. 动态偶遇（ambient encounter）【公开：路上会撞见小事件】
世界自己生成小事件，NPC 就地反应，形成"没脚本也热闹"。
**落到我们这里**：我们已有 meet（相遇）。缺的是"相遇要有由头"——现在相遇文字是生成的，
但不绑定一个触发（谁在哪儿、为什么撞上）。绑定"同街区 + 同时刻空闲"更合理。

## 二、与我们现有路线的关系（不新增战线）

| 借鉴项 | 接到哪 | 状态 |
|---|---|---|
| 日程表 | 年轮提示词的"此刻该干什么" | **缺**，可与 P2 planning 合并做（同一份"意图+时刻"表） |
| 目击→记忆 | memory_stream 的 importance | 零件齐，缺在场判定（1 行代码量级） |
| 态度值 | 关系边 + 措辞档位 | 缺强度字段 |
| 偶遇由头 | meet 候选生成 | 缺触发条件 |

## 三、结论

GTA/RDR 给的最大启发不是"更多 NPC"，而是**"世界有自己的时钟与因果"**：
- 时钟＝日程（人在该在的地方）
- 因果＝目击（看见才记得，记得才改变态度）

我们现在的居民有"记忆"和"关系"，但没有"**此刻**"和"**在场**"。这两样补上，才像城市而不是文本库。

优先级：**在场判定（最小、当天可做）→ 日程表（并入 P2）→ 态度值 → 偶遇由头**。
