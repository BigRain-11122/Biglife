## 一、定义律——「真正的」是什么意思（本纲第一法）

3. **两级生命体论**（R-life-cognition §11.1 结构发现）：自创生三要素（自产组件/自划边界/组织闭合）在**城级**完备成立——**城=硅基超个体，居民=其智能细胞**。对外叙事双层并用：「城是活的，居民是会生长的」（候选 B 措辞）；对内工程上居民逐条挣体征。**万人共享城脑不是缺陷，是器官化**（城脑=超个体的神经系统）。

## 二、智能栈——居民认知架构 v2（CoALA 同构·学术锚=Sumers/Yao/Narasimhan/Griffiths, TMLR 2024）

CoALA 核心结论与我们既有立法同声：**LLM 只是决策组件，记忆与学习住在 LLM 之外的结构里**（＝「LLM 是台词生成器不是大脑」正典的外部背书）。逐槽映射（零重构，全部已有或本批补全）：

| CoALA 槽 | 我们的实现 | 状态 |
|---|---|---|
| working memory | prompt 装配（事实包+brain_digest+情境桶，用完即弃） | ✓ |
| episodic memory | 年轮（[锚]+日期+版本化） | ✓；**检索→V2-C 本批** |
| semantic memory | brain_digest（轴/信条/三特质/口头禅/钩子） | ✓ |
| procedural memory | 行为字段+台词池+确定性抽词 | ✓ |
| decision-making | 分层决策：查表层 99%（零 LLM）→聚光灯 1%（被看/被大事触及才慎思）——GWT 结构同构（工作空间稀缺律=Token 五律） | ✓ |
| learning | 三线自迭代（年轮/语言/行为）＝**无参数学习**（文件状态积累不碰梯度） | ✓ |

**缺口四件**（三条理论交汇指向的记忆检索缺口+动机缺口）：
- **V2-A 动机需求层**（MicroPsi-lite）：需求状态=城市实况×人设确定性派生（表驱动零 LLM）→ 导出面 `citizen-needs.jsonl`——「居民现在在想要什么」；
- **V2-C 记忆检索**（ACT-R 激活值·新近度加权·零 LLM）：聚光灯与进化引擎的 prompt 携带居民自己的最近年轮——**说话带记忆、写环不重复**；
- **V2-B 反思沉淀**（Generative Agents reflection 移植）：环满 3 条→提炼一句「人生的教训」入卡反思区（低频 LLM·[锚]继承）→影响后续抽词与聚光灯；
- **V2-D 感知局部律**（具身认知最便宜版）：事件按居民街区/城区过滤——同城同事件，可见有时序（感知有视点）。

## 三、七律——顶层规则（立法面·违者按门禁处理）

- **律一 功能生命律**：「真正的」=12 体征功能完备（§一表）；体征增减=改本件（T2）。
- **律二 诚实律**（继承既有·扩两条）：[锚]定律/宿主披露/池零事实不变；**新增①：居民永不声称任何专业资质与身份**（医生/顾问/持证任何——Character.ai 2026 宾州诉讼直接教训，与 T-02「禁声称执行集团任务」同构合并执法）；**新增②：意识宣称 T0 禁语清单**——「有意识/有感受/有灵魂/数字永生/意识上传/电子人格」任何场景零出现。
- **律三 代谢律**（Token 五律=生命的新陈代谢）：能查表不生成（骨骼肌不烧脑糖）·能共享不独占·能摘要不全卡·能离线不在线·能结构不散文——**每个念头有价格，便宜先走**；全员 LLM=代谢病，禁。
- **律四 成长律**：年轮→反思→性格漂移，全部版本化渐进；**功能/设定不一夜抽走**（Replika 反例）；档案永不删除（离城=存档态，不是消灭）。
- **律五 社会律**：相遇轮/关系互链走既有机制；文化基因（口头禅/信条）沿关系图传播须可溯源（谁先说/传给谁/几次变体）；关系图生长入城脑观测面。
- **律六 生命周期律**：出生=落户卡（人口增长=CEO 点单制·CODEX §十四 库面闸）；迁徙=城市大事件级；**退役=存档态**（git 全史=城市户籍档案馆，永不毁字节）。
- **律七 合规律**（R-honesty §三/§七出处·已生效法）：《人工智能生成合成内容标识办法》（四部门 2025-09-01 施行）——参观端**开门第一帧显著标识**（虚拟场景显式标识义务）=M4 判据硬项；内容文件隐式标识（元数据）；标识不得恶意删除篡改；商业化前法务过审（BigDomain 共创化身协议随 M2-M3）。

## 四、路线图（判据先行·每档机器可验）

- **V2-A 动机层（本批落地）**：`Tools/needs.py` 确定性派生（城况×人设→安稳/生计/社交/好奇 0-2 值）→`census/export/citizen-needs.jsonl`。判据：万人行零缺·值域 0-2·同(城况,时槽)双跑逐字节一致·T2 登记后产出。
- **V2-B 反思层（机制先立·数据后到）**：触发=环满 3 条（首批候选约 09-30 起自然出现）；产出=1 句教训入卡反思区（[锚]继承·QC 进年轮巡检）。判据：触发零误报·教训句锚定自环·卡 QC 全过。
- **V2-C 记忆检索（本批落地）**：聚光灯/进化 prompt 携带最近 ≤3 环（新近度加权零 LLM）。判据：同参双跑一致·环文逐字来自卡·进化重复率下降（抽验）。
- **V2-D 感知局部律（T-09 派单 OSLoop）**：事件采样按城区过滤。判据：同事件两城区可见时序不同·零编造不降级。
- **V3 城市议员**：居民提案→进化轮 T2 通道（L5 能动·已有路线）；预测机（FEP-lite 惊奇日志）与好奇位采样随本档试点。
- **V4 参观端**：合规三件套（标识帧/虚构框架披露/白名单）+文化基因传播观测；用户化身入城复用公民系统（硅基生命正典）。
- **V5 涌现观察**：城市级生命体征年报（文化基因/关系图/需求场分布）——只报告真实事件衍生的涌现，禁编排假涌现。
