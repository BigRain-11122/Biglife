## 二、字段规范（消费端取用粒度）

1. **互聊台账**：`text`=卡面原文逐字（「与 <partner> 相遇：」后段）；`participants`=居民 ID 二元组；`source_ref`=census/registry/<城区>/<ID>.md:L<行号>；rumor_hop 行=字符集 ⊆ 事件原文 ∪ 垫话闭集（单源 import rumor_chain·零双建）。消费=直接引用原文，或指名改编（派生非编造·§三）。
2. **灵族志传说句**：一句定谳卡一句·已过准入六律（认祖/数据源/城市角色/传说句+温暖律+法务隔离）。消费=节目旁白/开场白/城内志怪单元；**改编不得破坏认祖链**（付丧神/城市机制/真天气三认祖轨随卡），出处按 §三 随行。
3. **城市生灵册**：羁绊/行为卡自带 census 实锚卡号——消费引用实锚=随行转引卡号（素材可溯源至居民卡面原文）。
4. **名人影射册**：消费红线**随引用传递**——安全距离四条（不指真名〔影射型〕/不用肖像/不仿嗓音/不冒称本人）+政治红线扫描器 66 词闭集基线（Tools/political_redline.py·R409）——BigStream 侧涉入城名再利用文本，沿用入城门三检口径。
5. **职业升华册人味句**：一句一职业·晋升叙事（温暖律·禁失业语义）——消费=职业故事单元/人物小传素材。

## 三、引用律（指针必带·源可溯 QC）

- 一切消费引用**必带指针**：册名+编号（§一「引用格式」列）或台账行 source_ref——零裸引=QC 拒收（interchat/city-chronicle 同律·源指针律）。
- 转引=素材进 BigStream 作品时保留一行出处（如「素材：BigLife《城市生灵册》#1 消息雀」或节目单/字幕级致谢列）——出处行格式 BigStream 侧自定·指针三要素（司名+册名或文件+编号）不可缺。
- 真实性律：**派生非编造**（令 §一.6）——改编自由·虚构情节不得冒充城内事实（census 居民/生灵/灵族=实名实卡·年轮=真实城市事件）。

## 四、点单制（反无消费方立项律）

- 本件=首版**供货清单级**交付（五面在册可查）。
- **扩产须点单**：新素材面/批量新条目（如互聊台账扩 kind、更多灵族个体入册、影射册后续批）——BigStream 任务单或集团转办件到本司任务板后才动工·禁止无消费方预产。
- 点单受理面=tasks/TASKS.md 新单（集团转办件最优先律）+集团 ledger P-号回执。

## 五、只读零写回

- BigStream 消费=**只读**：铁律④禁直写兄弟公司仓对向面——BigStream 不写本司任何文件；本司不写 BigStream 仓。
- 本司供货=素材本体在册即供（零接口服务/零导出新件·反无消费方立项律）；台账 append-only 永不删改（修卡后新文本落新行旧行存史=R446 契约）。
- 千篇一律禁令为**生产侧律**（本司生产链已注入·R408 复测 4/4）——消费侧再创作风格自由·批量复用不得反向污染本司生产面（零写回同款）。
