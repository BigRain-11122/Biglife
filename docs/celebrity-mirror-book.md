## §二 安全距离与真名直引执法（七卡逐卡适用）

1. **T4 公有域真名直引 ×2**（MIR-01 李白/MIR-02 孙悟空）：入城可用真名·样本句按公有域句式自由派生；仍禁肖像（无授权件在案）与声音克隆（型默认位=全合成设计声）。
2. **影射层致敬 ×5**（MIR-03~07）：**安全距离四条全带**——不指真名（原创影射名+真实姓名零同形）/不用肖像/不仿嗓音（声位=53 声纹池全合成基音 (sid,speed) 组合·kokoro 设计声）/不冒称本人（卡面永不宣称「我是某真实名人」）；词汇域=通识域（民俗「墨线/糯米」·梨园「台口/亮相」·大河意象「江/灯/桥」）·具体 IP 台词/歌词原文零直引；幽默面不拿真人性征开玩笑（样板 §三 细则③同律）。
3. **声音法务隔离律**：影射/T4 全部走型默认声位=设计声组合·**禁模仿真人嗓音**；真名/肖像/声音克隆三件=**P-09 法务闸未授权一律不启用**（令 §一.9·本批零授权件在案）。
4. **政治红线律**：七型主身份全=文化面（诗人/文学角色/学者人设/民俗师者/梨园老生/歌者/科幻机械体）——**零政治面**；古往今来风流人物滚动扩型时**政治人物主身份一律不入城**（词表=political_redline.py 66 词闭集·入城门必过）。

## §三 滚动分批入城机制（机制四段·令文「滚动分批入城机制（每批产能自定·QC=生成门+准入检查+政治红线）」逐款）

1. **段① 登记（先登记后使用）**：新影射型先扩 style-dna-archetypes（五维从史实/人设派生·禁通用模板）→ 本册追加卡行（追加式保原文·永不改写既有卡）；未登记型禁入城批。
2. **段② 入城批（常规生成管线）**：影射角色走 generate_census.py 家族常规管线新增面（活户籍红线沿：**既有万卡零触碰**·新增面专用件沿 add_honored_seats 先例·`--force` 重生成面恒禁）；入城卡**必带 style_dna+voice_profile 字段**（STYLE-FIELDS v1.0·影射/T4 缺 style_dna=拒绝入册）+双底座叙事链（未来形态——现实原型的升华后身——升华一句话）必答（生成门步① fail-fast 接线后执法）；声位=型默认位覆盖 md5 池选（voice-role-map 唯一新机制·型卡覆盖律）。
3. **段③ 三门 QC（全过才入册）**：①生成门=双底座链+升华三问（步①②机制面接线件·违律计数入 QC-REPORT）②准入检查=安全距离四条+型卡字段齐+声位合法（本册 §二/§五 断言面）③政治红线扫描器=political_redline.py 入城门 fail-fast（R409 已接线·REDLINE REFUSED 零静默改写）——任一门拒=整卡拒收零写入；过门后 export 同步+QC 巡检随批。
4. **段④ 产能与节律**：**每批产能自定**（令文）——首批=本册七卡（登记毕）；后续滚动批产能由当轮预算定（拆步律·勿硬撑）；入城后=常规居民同律（年轮/台词/相遇/反思生态全接入·人各一声席位生效）。

## §四 法务边界（红线四条）

1. 真名/肖像/声音克隆=P-09 法务闸域·未授权一律不启用（授权后真名深化=准入路线第三路·本批不涉）。
2. 影射卡永不冒称本人（「我是某真实名人」禁令·与灵族志「我是某真实死者」同族条款）。
3. 政治人物主身份一律不入城（政治红线律·扩型预检必过）。
4. 肖像面：本册零图像资产登记——形象面走 census 形象律（CODEX §七.1）·AI 肖像生成前须过形象面既有判据（CEO 样张批 2 认可窗）。
