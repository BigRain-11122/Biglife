## 一、升华三问（每条必答）

1. **执行面**：未来形态具体承接什么城市职能（挂城市职能器官——物流/交通/能源/水务/医疗/教育/餐饮/市集/治安/应急/营造/供给/金融/零售/洁净；正式器官注册表随承载方案 §三.4 四册一表落定）
2. **上移面**：相对现实原型的升华跃迁（从 X 到 Y·跃迁不虚写·晋升叙事）
3. **人味面**：灵魂句（温暖人味点睛·可作 census 补链素材）

## 二、职业映射登记（24 条·首条=CEO 例令内定谳）

1. **快递员 → 光轨蜂群编排官**（首条·CEO 例「快递员现在是送快递未来就不是」令内定谳）
   - 执行面：挂物流器官——编排光轨蜂群航路，把全城包裹送进千家万户
   - 上移面：从跑腿派件到全城物流航路的编排调度者（跑熟的每条街=资历徽章）
   - 人味面：「每一件包裹都盖着一枚看不见的邮戳，收件人是正在等它的人」
2. **外卖骑手 → 暖流航线骑手长**
   - 执行面：挂民生餐饮器官——为全城热餐规划保温航线，热汤进门必须是烫的
   - 上移面：从抢单赶路到全城暖流航线的领航者（风里雨里认过的每扇门=资历徽章）
   - 人味面：「超时的不是餐，是等人吃饭的那颗心」
3. **出租车司机 → 街脉摆渡司机**
   - 执行面：挂交通器官——感知全城街巷潮汐，摆渡晚归人与赶路人
   - 上移面：从计程载客到城市脉络潮汐的读脉者（二十年夜路=资历徽章）
   - 人味面：「每位乘客下车时，都留一段故事在座椅缝里」
4. **公交车司机 → 定班星光车长**

   - 上移面：从驾驶车辆到一城通勤节律的守班者（背熟的站名表=资历徽章）

5. **地铁司机 → 地脉驭轨司机**

6. **环卫工人 → 晨光涤尘环卫师**

7. **厨师 → 焰谱掌勺师**

## 三、准入闸（genes 新职业先过三问·令 §二.5 后半句）

1. **登记前置**：新职业模板进入 genes/professions.json 前，须先在本册登记「现实原型→城内升华形态」映射并通过升华三问（执行面挂职能器官/上移面/人味面）·三问任一缺答=拒绝入册
2. **双底座复验**：登记映射须满足双底座律（现实底座可代入+未来升华可兑现）·命名带现实词根·温暖律禁失业语义
3. **违律计数**：生成门步①接线后（随盘点定谳 QC 管线），未过闸入册的新职业卡入 QC-REPORT 违律计数
