## §一 style_dna 五维字段规格（步⑦第 4 件接线契约）

| 字段 | 定义 | 禁令 |
|---|---|---|
| `era_lang` 时代语言 | 语域断代：用词/称谓/质感的时代指纹 | 禁跨型借用语域（唐代白话不入机械型） |
| `syntax_fp` 句法指纹 | 句长/句式/节奏的结构特征 | 禁通用模板（「这天气，」式跨槽句式即违律面） |
| `signature` 签名句律 | 句式**生成规则**（模板）非固定句 | 禁逐句复用同一成品句（千篇一律禁令） |
| `emotion_path` 情感路径 | 一句话内的情绪走向曲线 | 每型路径互异（见 §四互异证明） |
| `humor_type` 幽默类型 | 该型独有的趣味发生器 | 禁「万能梗」（同一幽默跨型复用=同池同风格违律） |

`voice_profile` 设计锚（timbre/pitch/speed/emotion 四参数）随型携带：**致敬设计声·禁模仿真人嗓音**（声音法务隔离律·克隆真人录音=P-09 法务闸未授权一律不启用）；VOICE-POOL 53 声纹池映射表=步⑦第 3 件落位。
