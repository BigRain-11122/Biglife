# 年轮开口族闸扩面 + 照抄示例原句闸（R2760 · 2026-11-13）

站别：出生站（生成端 `ring_violations`）
法源：`Tools/ring_open_family.py` v1.2（族配额闸）+ `Tools/evolve_citizen.py`（消费/提示/拒稿）
前案：R2581（T-20261112-04 族配额闸）、R2608（^手边 补盲）、R2586（第二句软引导）

## 一、本轮实测（口径=registry 正典正文，2026-11-13）

```
python -X utf8 Tools/ring_open_family.py --check 2026-11-13
date=2026-11-13 rings=552 quota=25%
  HAND_DEICTIC         221   40.0%  <- OVER
  TIME_OPEN              1    0.2%
  WEATHER_ABSTRACT       0    0.0%
  PROP_DEICTIC         171   31.0%  <- OVER
verdict: OVER
```

两条实证：

1. **旧闸少算 15 个点**：`^手里/手中的` 不在 HAND 族正则里（与 R2608 的 `^手边`
   漏判同型）。补上后手部族由 138/552=25.0%（刚好卡在阈值下、不触发）变为
   221/552=40.0%（实为超线）。也就是说 11-13 全天四成居民从「手」起句，
   而闸当天判 PASS——**闸失效不是阈值问题，是族定义漏了助词面**。
2. **器物指示族完全无闸**：`PROP_DEICTIC`（那台／那口／那架／这把…起句）
   171/552=31.0%，此前不在任何族里，不参与配额判定。

## 二、缺陷出生地（可追因果）

`evolve_citizen` 的族闸提示词在「禁手族」之后给出逃生示例：

> 换这几种开头之一：写一件物的状态（「那口锅底又薄了一层」）、
> 写你正看着的另一样东西（「账本翻到第三页」）…

今日实测这两句被**逐字复写**：

| 示例原句 | 今日复写条数 | 占当日 |
|---|---|---|
| 账本翻到第三… | 30 | 5.4% |
| 那口锅底又薄… | 18 | 3.3% |
| 合计 | 48 | 8.7% |

即：**闸把模型从手族推出去，提示词又把模型领进器物族**，而且示例本身成了
全城 canned 句。这与模块自注「修一个生一个」同源（R2581 §二）。

## 三、本轮改动（两处，均在既有工具内）

1. `Tools/ring_open_family.py`
   - `HAND_DEICTIC` 增 `^手里`、`^手中的`（补助词盲区，承 R2608 判据）。
   - 新增族 `PROP_DEICTIC`：`^那[台口架把扇盏辆本件个只座棵张块根条片串副支]`
     与 `^这[同集]`。族按形状判、不按词义（一句「那口锅」合法，全天三成
     从指示代词起句才是病）。
   - selftest 增四探针：`pos-hand-in-palm`、`pos-prop-deictic`、`pos-prop-this`、
     `neg-prop-midsentence`、`neg-prop-body`（句中/非首句不误伤）。
2. `Tools/evolve_citizen.py`
   - `FAMILY_OPEN_HINTS` 增 `PROP_DEICTIC` 人话标签（否则提示词打印原始族名，
     模型被拒而不知为何 = gap #68 复现条件）。
   - 逃生示例改写：三条形状示意，并显式写「**严禁照抄原句**」。
   - 新增出生站拒稿码 `prompt-example-echo`：年轮开头 16 字内命中
     `PROMPT_EXAMPLE_ECHO` 台账（6 条 canned 句）即退回重写。新增示例必须同步
     登记台账，否则下一轮又会以 canned 句成为全城开头。
